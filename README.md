Data Mining Practicals This repository contains my Data Mining practical work using Python and Jupyter Notebook.
In these practicals, I have worked with different datasets and applied basic Data Mining and Machine Learning techniques.

Practicals Performed
1. Library Import
Imported the required Python libraries.
Prepared the environment for Data Mining tasks.
2. Iris Dataset
Imported the Iris dataset.
Checked the total number of rows and columns.
Separated input features and output labels.
Applied Decision Tree Classification.
Checked model accuracy.
Created a Decision Tree diagram.
3. Market Basket Analysis
Created a small shopping dataset containing Bread, Milk, and Butter.
Applied the Apriori algorithm.
Found frequent itemsets.
Generated association rules.
Checked Support, Confidence, and Lift.
Created a bar chart to show frequent itemsets.
4. Salary Dataset and Linear Regression
Searched for and imported the Salary CSV file.
Displayed the first five rows of the dataset.
Checked rows, columns, and column names.
Selected YearsExperience as input (X).
Selected Salary as output (Y).
Divided the data into training and testing sets.
Applied Simple Linear Regression.
Predicted salaries based on years of experience.
Compared actual and predicted salaries.
Calculated MAE, MSE, RMSE, and R² Score.
Created a graph showing actual data and the regression line.
